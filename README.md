# SupportFlow

A modern customer support management system where customers can create support tickets and support agents can manage and respond to those tickets.

## Demo Agent Account

> **Note:** These are demo credentials created specifically for testing the application.

## Features

* User Authentication
* Role-Based Access
* Customer Dashboard
* Agent Dashboard
* Create Support Tickets
* Manage Tickets
* Update Ticket Status

## Tech Stack

### Frontend

* React
* React Router
* Tailwind CSS
* Axios

### Backend

* Node.js
* Express.js
* MongoDB

## Getting Started

Clone the repository:

```bash
git clone <your-repository-url>
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm run dev
```
